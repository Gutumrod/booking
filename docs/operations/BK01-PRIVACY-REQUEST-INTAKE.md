## 2. คำขอที่รับ (ขอบเขต V1)

รับคำขอ 4 ประเภท (สิทธิ์ตาม PDPA ที่ประกาศไว้):

| ประเภท | ตัวอย่างคำขอ |
| --- | --- |
| ขอเข้าถึง/ขอสำเนา | "ขอข้อมูลส่วนตัวที่ระบบเก็บไว้" |
| ขอแก้ไขให้ถูกต้อง | "เบอร์โทรผิด ขอแก้" |
| ขอลบ | "ขอลบข้อมูลของฉัน" |
| ขอจำกัด/คัดค้าน/ถอนความยินยอม | "ขอให้หยุดใช้ข้อมูล" |

**ข้อควรรู้ก่อนรับเป็นคำขอของเรา:**
- ข้อมูลลูกค้าปลายทางของร้าน = **ร้านเป็น Controller / WSTERA เป็น Processor** (A-27)
  ⇒ โดยหลัก **ส่งต่อคำขอให้ร้านวินิจฉัย** เว้นแต่ Owner สั่งเป็นอย่างอื่น — [[OWNER INPUT: นโยบายส่งต่อคำขอของลูกค้าปลายทางให้ร้าน (ผู้ควบคุมข้อมูล) และกรณีที่ WSTERA ดำเนินการเอง]]
- คำขอที่เกี่ยวกับ**ค่าบริการ WSTERA (Stripe)** = WSTERA เป็น Controller จัดการเอง

## 3. ขั้นตอนตอบ (ทีละข้อ)

1. **รับและลงทะเบียน** — ทุกคำขอต้องได้เลขที่ (`PRIV-YYYYMMDD-NN`) และถูกบันทึกใน §5 ทันที
2. **ตอบรับเบื้องต้น** — แจ้งว่าจำได้รับแล้วและกำลังตรวจสอบ (ไม่สัญญาเวลาที่ทำไม่ได้)
3. **ยืนยันตัวตนผู้ขอ** — ตามวิธีที่อนุมัติ (ไม่เก็บรหัสผ่าน/เลขบัตร/สลิปเต็มในอีเมล — ดู `privacyNote` ในแอป)
   [[OWNER INPUT: ขั้นตอนตรวจตัวตนผู้ขอใช้สิทธิ์ที่ทนาย/Owner อนุมัติ]]
4. **ยืนยันขอบเขต** — ระบุว่าจะจัดการข้อมูลชุดใด ที่ร้านไหน/ช่วงเวลาใด
5. **แยกสามกองก่อนแตะข้อมูล** — ลบได้ / anonymize / ต้องเก็บ (เหตุผลกฎหมาย/บัญชี/ข้อพิพาท)
6. **วินิจฉัยว่าจะส่งต่อให้ร้านไหม** (§2) และบันทึกเหตุผล
7. **ดำเนินการ** ตาม `BK01-DATA-DELETION-RUNBOOK.md` (dry-run → คนที่สองยืนยัน → ลบ/anonymize → ตรวจ hold)
8. **แจ้งผลให้ผู้ขอ** — บอกว่าเก็บอะไรไว้และเพราะอะไร (ห้ามลบแล้วเงียบ)
9. **ปิดคำขอ** — จดวันที่ปิด ผลลัพธ์ และข้อยกเว้นใน §5

**ระยะเวลาตอบกลับ:** [[OWNER INPUT: ระยะเวลาตอบกลับคำขอใช้สิทธิ์ที่ทนาย/Owner อนุมัติ (ห้ามเดา — ร่างนี้ไม่สัญญาเวลาจนกว่าจะยืนยัน)]]
**ผู้รับผิดชอบหลัก (owner ของกระบวนการ):** [[OWNER INPUT: บทบาทผู้รับผิดชอบรับและตอบคำขอความเป็นส่วนตัว]]

## 4. ตัวอย่างคำตอบ (เชิงข้อความ — ให้ Owner/ทนายตรวจก่อนใช้)

**ตอบรับ:**
```
เรียน ท่าน
เราได้รับคำขอของท่านแล้ว (เลขที่ PRIV-YYYYMMDD-NN) และกำลังตรวจสอบ
หากต้องการยืนยันตัวตนเพิ่มเติม เราจะติดต่อกลับทางช่องทางที่ท่านให้ไว้
(ยังไม่กำหนดเวลาตอบกลับเป็นทางการในร่างนี้)
```

**แจ้งผล:**
```
เรียน ท่าน
ผลคำขอเลขที่ PRIV-YYYYMMDD-NN: ดำเนินการแล้วในส่วนที่ทำได้
ส่วนที่เราเก็บไว้ต่อ: <รายการ> เพราะ <เหตุผลกฎหมาย/บัญชี/ข้อพิพาท>
หากไม่เห็นด้วย ท่านติดต่อกลับได้ที่ privacy@wstera.com
```

**ห้ามสัญญาในคำตอบ:** ระยะเวลาตอบกลับ · การลบข้อมูลที่มีหลักฐานการเงินผูกอยู่ · การลบที่ทำลายหลักฐานทางบัญชี

## 7. กฎเหล็กที่ห้ามฝ่าฝืนในกระบวนการนี้

- **ห้ามลบหลักฐานทางบัญชี/ข้อพิพาทเพื่อปิดคำขอ** — ถ้าต้องเก็บ ให้เก็บและแจ้งตามจริง
- **ห้าม DELETE booking ที่มี `deposit_money_events`** — ทำได้แค่ anonymize (ยังไม่มีในระบบวันนี้ ⇒ ระงับ + ส่งต่อ)
- **ห้ามสัญญาเวลาตอบกลับ/กลไกอัตโนมัติที่ยังไม่มี** ในเอกสารนี้หรือในข้อความถึงลูกค้า
- **ห้ามเก็บรหัสผ่าน/เลขบัตร/สลิปเต็มในอีเมล** ที่รับคำขอ
