# BK01 Go-To-Market

**Status:** LOCKED STRATEGY — execution waits for BK-A/B gates

## Beachhead
Single-location barber/hair/beauty/nail businesses in Thailand with 1–10 providers, meaningful appointment volume and active LINE customer communication. Prefer businesses already feeling schedule/deposit/no-show friction over businesses seeking only a generic website calendar.

## Acquisition sequence
1. **Founder-led pilot recruitment:** targeted outreach to qualifying shops with a concrete workflow audit and 14-day guided pilot.
2. **Proof capture:** permissioned before/after operational evidence, onboarding friction, support burden and merchant quotes.
3. **Referral loop:** ask only after merchant reaches first value and has handled real bookings successfully.
4. **Content/SEO/social:** practical Thai content around booking workflow, deposit policy, LINE operations and schedule mistakes; CTA to trial/pilot.
5. **Paid acquisition:** only after activation, retention and support economics are measurable; do not buy traffic into an unproven onboarding funnel.

## Pilot offer
- one shop / primary ICP only;
- guided setup but measure every manual intervention;
- use provisional price/WTP discussion without pretending public price is final;
- success measured by operational adoption and first value, not signup count.

## Funnel
Qualified visit/outreach → signup started → signup completed → shop provisioned → service/staff/schedule setup → booking link published → real booking confirmed → first value → trial review/WTP → paid activation.

## Channel fit
LINE/Facebook/local-business communities fit because the ICP already operates customer communication socially; Google search/content captures active intent around booking systems. Marketplace-style customer acquisition is not the BK01 model.

## Stop conditions
Pause acquisition if booking collision/security incident occurs, setup requires persistent WSTERA intervention, notification/deposit reliability falls below release gate, support burden is uneconomic, or merchants consistently reject the value proposition at proposed price.
